一、项目摘要

SPVE 是一款以角色为核心商业化载体、以 TPS 刷宝射击为核心体验、以复古朋克与暗黑微恐世界观为差异化表达的 PVE 长线游戏项目。

角色负责吸引与留存，射击负责即时爽感，掉落与 Build 负责长线寿命，世界观负责差异化记忆点。

核心目标

  • 用 TPS 视角增强角色露出、人设联结和外观价值。
  • 用刷图、掉落、改枪和 Build 构筑形成可重复游玩的核心循环。
  • 用高记忆点场景构建世界观差异化。

产品口径

  • 不是单纯二次元射击。
  • 不是传统写实暗黑刷宝。
  • 而是“风格化角色 + 暗黑微恐世界 + 复古朋克异常物件”。

二、立项背景与品类机会

刷宝游戏的核心吸引力来自“进入关卡—击杀敌人—获得掉落—优化构筑—挑战更高难度”的持续循环。该循环天然支撑长线游玩、装备追求、角色成长和社交讨论。

PVE 低压力

相较纯竞技射击，PVE 更适合低精力消耗的重复游玩，也更容易通过难度分层服务不同水平玩家。

二游角色优势

二游擅长角色标签、视觉设计、剧情包装和长线运营，但纯明亮二游表达并不天然适配刷宝。

移动端待验证

移动端是核心验证方向，PC 更适合作为品质展示与补充平台，不宜早期重度押注。

三、项目定位

项目定义为：一款角色驱动的风格化暗黑朋克 TPS 刷宝射击游戏。

卖点说明
角色驱动角色具备年代感、美感、个性和 Cos 欲望，是商业化与情感连接的核心载体。
TPS 刷宝射击第三人称射击承接角色露出与战斗爽感，形成刷图、掉落、改枪、Build 的循环。
复古朋克世界以原子朋克、复古未来主义和多地域朋克主题构建差异化世界。
暗黑微恐怪物怪物偏肉质、胶质、类人或动物，机械占比受控，强化击杀爽感。
智能推荐 Build大 Build 库结合智能推荐，兼顾易上手与难精通。

四、世界观与概念风格

世界观以原子朋克、复古未来主义和乌托邦崩坏为基础，向美式朋克、中式朋克、欧洲朋克等主题扩展。苏式朋克初期不作为主展示方向，可作为背景或侧面区域存在。

角色风格化保留二游式角色标签、职业幻想、年代感和外观商业化空间。
物件复古朋克冰箱、游乐设施、电视台设备、售票机等现实物件被智能化、智械化、异常化。
世界反乌托邦公共娱乐、宣传、度假、家庭消费等安全意象逐渐腐坏。
怪物暗黑微恐以肉质、胶质、类人、动物和智械污染为主体，机械怪比例不宜过高。
内部艺术口径：表皮明亮，底层腐坏；角色好看，世界不安全。

反派与核心冲突

世界中存在全球最强的 N 个 AI 智能，但真正领导它们的仍然是人类。世界危机并非单纯的智械暴走，而是人类欲望、制度工程和 AI 管理共同导致的乌托邦崩坏。

五、核心玩法设计

项目以《遗迹 2》作为战斗与关卡体验的重要参考，采用 TPS 视角为主。TPS 有利于角色身体、服装、动作和外观的持续露出，也更适配二游式角色商业化。

核心循环

选择角色、职业、武器和推荐 Build。
进入主题关卡或副本区域。
通过 TPS 射击、技能模组、道具和增强型大招清理怪群。
遭遇精英怪、随机事件、地图 Buff 或掉落节点。
挑战现实物件异常化 Boss，获得暗黑式掉落并优化 Build。

上手与深度

项目坚持“易上手，难精通”。新手阶段提供默认流派，中期提供智能推荐搭配，深度阶段开放自由构筑。AI 分析能力可用于词条理解、装备评分、流派推荐和副本适配建议。

六、武器、职业与 Build 系统

武器设计以真实武器为基础，进行复古朋克演绎。角色属于职业大类，职业适配推荐武器，但不完全限制玩家选择。

流派定位初步设计方向
突击步枪流中庸稳定以 M4、AK 等典型原型为基础，适合作为默认和新手流派。
喷子流近距离爆发弹丸散布、低射速、低弹匣，可扩展独头弹、燃烧弹、鸟弹、鹿弹等。
冲锋流高射速近距离强调移动压制、贴脸输出和连杀节奏。
射手 / 狙击流远程精确强调弱点打击、精英处理和 Boss 阶段输出。
召唤流机器人联动射击通过机器人、炮台、无人机等形成协同作战。

技能模组与状态

投掷类

爆发、控制、区域封锁。

Buff 类

强化射击、换弹、移动、生存。

机动类

位移、闪避、脱战、追击。

Debuff 初步包括流血、燃烧、感电、中毒。元素反应可以考虑，但不宜过度数值化，应保持直观可感知。

七、内容规划

怪物设计

怪物优先服务击杀爽感和暗黑式掉落可信度，方向包括肉质、胶质、类人、动物、现实物件与生物组织融合、智械污染导致的畸变。

Boss 设计

Boss 采用现实物件异常化原则，例如智械化冰箱、失控游乐设施、异常电视主播、清洁机器人集群、乐园吉祥物等。

关卡 Demo 方向

朋克主题乐园

天然具有关卡结构、视觉辨识度和首曝传播力，可呈现明亮表皮下的腐坏。

电视台

适合作为宣传主阵地，展示世界观、AI 管理、社会控制和舆论包装。

度假小镇

与世界观关键事件绑定，兼具生活感和危机感。

微缩小镇

展示人的气息、日常空间和异常尺度变化。

八、终局与长线运营

项目希望形成具备长尾寿命的终局结构：初始版本提供 100 小时以上有效内容，终局系统支撑 500 小时以上长尾追求。

终局结构

随机地图、地图 Buff 随机、掉落赌博感、词条追求、多角色养成驱动和社交展示钩子。

单局节奏

单局约 20 分钟，以 5 分钟为一个小节，并支持中途保存，适配移动端碎片化游玩。

长线更新

新角色、新地图、新剧情、新 Boss、新武器、新职业分支和新终局规则。

九、商业化设计

商业化应以角色厨力、外观、武器外观和轻量数值为主。当前不建议重度依赖传统二游的强命座、强专武模式，以免破坏刷宝游戏中装备掉落和自由构筑的公平感。

玩家因为角色而进入，因为射击和掉落而留下，因为 Build 和终局而长期游玩，因为外观和表达而付费。

可商业化内容

  • 角色外观、武器外观、主题套装。
  • 职业幻想装扮、特效外观。
  • 轻量成长便利、赛季通行证、收藏展示内容。

商业化边界

  • 避免强数值压倒刷宝循环。
  • 避免强命座、强专武造成口碑风险。
  • 优先让付费服务表达，而不是替代刷图追求。

十、首曝 PV 方向

首曝 PV 的核心任务是建立项目定义、产品品质、角色厨力、战斗爽感和 Build 想象。

主角团登场，建立角色标签。
危机出现，呈现智械危机或乌托邦崩坏。
切换战斗形态、装备和武器，展示 TPS 角色露出。
重点展示武器改装和刷怪爽感。
Boss 战、暗黑式掉宝、推荐装配和多场景混剪。

十一、团队核心能力需求

能力方向要求
概念与世界观建立复古朋克、暗黑微恐和风格化角色融合的稳定口径。
角色设计完成高标签角色的人设、形象、剧情故事和商业化表达。
射击刷图爽感设计枪械、命中反馈、怪物死亡、关卡节奏和 Boss 机制。
数值 Build设计掉落、词条、技能、成长系统和终局循环。
商业化围绕角色、外观和武器表达设计低反感度付费内容。

十二、关键风险与验证计划

风险说明验证方向
移动端刷宝需求不确定移动端玩家是否愿意长期重复刷图仍需验证。用研、买量测试、竞品观察。
二次元与刷宝融合风险纯二游表达可能削弱暗黑掉落和击杀爽感。以“风格化角色 + 暗黑微恐世界”做概念验证。
TPS 枪感不足TPS 有利于角色露出，但枪感可能弱于 FPS。验证开镜、命中、换弹、受击和死亡反馈。
Build 复杂度过高大 Build 库容易造成上手门槛。默认流派、智能推荐、阶段化解锁。
美术融合失败二游角色、暗黑微恐和复古朋克可能变成拼贴。先建立统一艺术口径和一张 Demo 场景。
最小验证闭环：一名高标签角色、一类武器流派、一张主题乐园或电视台关卡、一套基础掉落与 Build、一个现实物件异常化 Boss、一段 60-90 秒核心体验视频或可交互 Demo。

十三、立项建议

基于当前内容，SPVE 具备继续推进立项论证的价值，但不建议直接进入完整产线投入。更合理的方式是进入概念验证阶段，围绕“风格化暗黑朋克 TPS 刷宝”建立最小闭环。

判断

  • 方向价值：成立。
  • 差异化：有潜力。
  • 主要不确定性：移动端需求、TPS 枪感、Build 复杂度、美术融合和商业化边界。

建议

项目可进入早期概念验证阶段。验证重点应聚焦于“风格化角色是否能带动暗黑微恐刷宝射击成立”，以及“移动端 TPS 刷图 + 掉落 Build 是否具备足够长期吸引力”。
