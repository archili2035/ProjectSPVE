核心判断

第一钩子最重要。

很多项目的失败，不是失败在宣发阶段，而是在最初选择的第一钩子天花板不够高时，已经失败了。

好的宣传片，应该先让玩家被第一钩子吸住，再用品质、美和实机证明这个钩子值得相信。

1. 第一钩子

第一钩子可以是题材、世界观、剧情、人设、玩法，也可以是题材与玩法的高度契合。

最好的情况是：题材和玩法互相证明，而不是简单叠加。

“XX 题材的 XX 玩法”如果只是换皮，玩家在知道概念的那一刻就已经失去大部分兴趣。

引起共鸣保留想象空间不是一眼看完不是简单换皮

2. 高品质

宣传片需要高品质。品质的作用是放大第一钩子，而不是替代第一钩子。

3. 美

美不是庸俗的漂亮，但核心角色、主视觉、场景和怪物不能让人反感、不喜。

4. 实机

实机比例可随阶段变化，但必须证明前面的概念，而不是证伪它。

5. 天花板

如果第一钩子没有天花板，后面的品质、演出和实机很难补回来。

维度判断问题
第一钩子是否足够有共鸣和想象空间？
题材玩法契合是否不是简单换皮，而是互相增强？
高品质是否让玩家相信项目有完成度？
美核心对象是否让人愿意看、愿意记住？
实机是否证明而不是证伪前面的概念？
