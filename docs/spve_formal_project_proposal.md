# SPVE 项目立项书（正式整理版）

> 文档版本：V0.1  
> 整理日期：2026-08-19  
> 项目代号：SPVE  
> 项目类型：角色驱动的 PVE 刷宝射击项目  
> 当前阶段：早期立项论证 / 概念验证准备

---

## 一、项目摘要

SPVE 是一款以角色为核心商业化载体、以 TPS 刷宝射击为核心体验、以复古朋克与暗黑微恐世界观为差异化表达的 PVE 长线游戏项目。

项目希望在传统射击游戏的即时反馈、刷宝游戏的掉落与 Build 深度、二游的角色标签与长线运营能力之间建立结合点。整体方向不是单纯的“二次元射击”，也不是传统写实暗黑刷宝，而是以“风格化角色 + 暗黑微恐世界 + 复古朋克异常物件”为主要艺术与产品口径。

项目核心目标可以概括为：

- 用 TPS 视角增强角色露出、人设联结和外观价值；
- 用刷图、掉落、改枪、Build 构筑形成可重复游玩的核心循环；
- 用复古朋克、主题乐园、电视台、度假小镇等高记忆点场景构建世界观差异化；
- 用轻量数值、重外观的商业化方式，避免强命座、强专武对口碑和刷宝公平感的破坏；
- 用智能推荐搭配降低 Build 系统上手门槛，同时保留深度玩家的自由构筑空间。

## 二、立项背景与品类机会

### 2.1 PVE 刷宝体验的长期需求

刷宝游戏的核心吸引力来自“进入关卡—击杀敌人—获得掉落—优化构筑—挑战更高难度”的持续循环。该循环能够天然支撑长线游玩、装备追求、角色成长和社交讨论。

相较于纯竞技射击，PVE 刷宝射击具有以下优势：

- 竞争压力较低，更适合轻松休闲和低精力消耗的重复游玩；
- 可通过装备、词条、技能、角色和地图随机性持续扩展内容；
- 对玩家操作强度要求可分层，既能容纳普通玩家，也能服务深度玩家；
- 可通过赛季、活动、副本、Boss 和新角色持续更新。

### 2.2 二游角色商业化与刷宝循环的结合机会

二游在角色塑造、视觉标签、阵营组织、剧情包装和外观商业化方面具有明显优势。其玩家群体普遍接受 PVE、剧情、角色养成和长期运营内容。

但纯二次元表达并不天然适配刷宝。刷宝需要怪物击杀欲、暗黑式掉落可信度、危险区域探索感和长期重复刷图的压迫感。因此，本项目不建议采用纯明亮、轻冒险式的二游风格，而应采用更复合的方向：

> 角色保持风格化和商业化弹性，世界和怪物承担暗黑微恐、反乌托邦与异常感。

### 2.3 平台判断

当前判断为：移动端是核心验证方向，PC 可作为品质展示与补充平台，但不宜在早期重度押注。

原因包括：

- PC 端射击用户仍以竞技游戏和高强度操作体验为主；
- 移动端更适合低精力、碎片化、重复刷图的产品形态；
- TPS 视角在移动端更利于角色展示、外观价值和操作包容度；
- PC 端可承担高品质画面展示、买量素材、核心玩家口碑和后续跨端能力。

需要重点验证的是：移动端用户是否存在足够明确的“刷宝射击”需求，以及该需求是否能够被角色驱动型 PVE 产品承接。

## 三、项目定位

### 3.1 产品定义

SPVE 可定义为：

> 一款角色驱动的风格化暗黑朋克 TPS 刷宝射击游戏。

更完整的产品描述为：

> 玩家操控具有强人设标签和职业定位的风格化角色，进入复古朋克乌托邦崩坏后的异常区域，通过 TPS 射击、技能模组、武器改装、暗黑式掉落和 Build 构筑，完成反复刷图、挑战 Boss、收集装备、养成角色和探索世界真相的长线体验。

### 3.2 核心卖点

| 卖点 | 说明 |
|---|---|
| 角色驱动 | 角色具备年代感、美感、个性和 Cos 欲望，是商业化与情感连接的核心载体。 |
| TPS 刷宝射击 | 以第三人称射击承接角色露出与战斗爽感，形成刷图、掉落、改枪、Build 的循环。 |
| 复古朋克世界 | 以原子朋克、复古未来主义和多地域朋克主题构建差异化世界。 |
| 暗黑微恐怪物 | 怪物偏肉质、胶质、类人或动物，机械占比受控，强化击杀爽感。 |
| 高记忆点关卡 | 主题乐园、电视台、度假小镇、微缩小镇等空间天然具有关卡结构和传播辨识度。 |
| 智能推荐 Build | 大 Build 库结合智能推荐，兼顾易上手与难精通。 |

### 3.3 目标用户

项目初步面向以下用户：

- 喜欢 PVE、刷图、掉落和角色养成的二游玩家；
- 喜欢《遗迹 2》《无主之地》《Warframe》等射击刷宝或 Build 构筑体验的玩家；
- 对复古朋克、暗黑微恐、异常物件、反乌托邦题材感兴趣的内容型玩家；
- 希望获得低竞技压力、可长期投入、可持续优化构筑的移动端玩家。

## 四、世界观与概念风格

### 4.1 世界观基底

世界观以原子朋克、复古未来主义和乌托邦崩坏为基础。项目可以在此基础上延展出不同区域主题，例如美式朋克、中式朋克、欧洲朋克等。

为避免与既有作品产生过强的直接联想，苏式朋克不建议作为首发主视觉方向，可作为背景、历史遗产或侧面区域存在。

### 4.2 艺术口径

推荐的内部艺术口径为：

> 表皮明亮，底层腐坏；角色好看，世界不安全。

具体拆解如下：

- **角色风格化**：保留二游式角色标签、职业幻想、年代感和外观商业化空间；
- **场景反乌托邦**：公共娱乐、宣传、度假、家庭消费等安全意象逐渐崩坏；
- **物件复古朋克**：冰箱、游乐设施、电视台设备、售票机、清洁机器人等现实物件被智能化、智械化、异常化；
- **怪物暗黑微恐**：以肉质、胶质、类人、动物和智械污染为主体，机械怪比例不宜过高；
- **调性复合**：外层热血、燃、幽默，底层保留黑暗、人性和制度腐坏。

### 4.3 反派与核心冲突

反派方向可参考“乌托邦建立者”类型：

- 世界中存在全球最强的 N 个 AI 智能；
- AI 代表高度理性、效率和秩序；
- 但真正领导它们的仍然是人类；
- 世界危机并非单纯的智械暴走，而是人类欲望、制度工程和 AI 管理共同导致的乌托邦崩坏。

这种设定的优势是：反派不只是“邪恶 AI”或“失控机器”，而是具有理念、秩序和现实隐喻的复杂系统。

## 五、核心玩法设计

### 5.1 基础玩法方向

项目以《遗迹 2》作为战斗与关卡体验的重要参考，采用 TPS 视角为主。

选择 TPS 的原因：

- 有利于角色身体、服装、动作和外观的持续露出；
- 更容易建立玩家与角色之间的联结；
- 更适配二游式角色商业化；
- 对移动端玩家更包容；
- 可以积累动作流畅度、开镜手感、枪械反馈等射击基础能力。

TPS 的主要代价是枪感相较 FPS 会有一定折扣。因此，项目早期需要重点验证：开镜体验、命中反馈、换弹节奏、受击硬直、怪物死亡反馈和武器差异化。

### 5.2 核心循环

项目核心循环为：

1. 选择角色、职业、武器和推荐 Build；
2. 进入主题关卡或副本区域；
3. 通过 TPS 射击、技能模组、道具和增强型大招清理怪群；
4. 遭遇精英怪、随机事件、地图 Buff 或掉落节点；
5. 挑战现实物件异常化 Boss；
6. 获得暗黑式掉落、词条装备、武器改装材料或角色成长资源；
7. 优化 Build，进入更高难度或终局内容。

### 5.3 大招与技能原则

项目可以保留强表现力大招，但不应走动作二游式的长播片、强表演、纯灌伤害路线。

推荐原则：

- 大招服务射击，而不是替代射击；
- 大招可以强化、异化或临时改变武器行为；
- 大招可以表现为脱手道具、战场装置、召唤物或区域控制；
- 视觉表现要有记忆点，但不能破坏刷图节奏。

### 5.4 上手与深度

项目应坚持“易上手，难精通”。

Build 系统可以具有较大深度，但早期体验必须可被推荐系统承接：

- 新手阶段提供默认流派；
- 中期提供智能推荐搭配；
- 深度阶段开放自由构筑；
- AI 分析能力可用于词条理解、装备评分、流派推荐和副本适配建议。

可参考三角洲的改枪推荐、金铲铲的阵容推荐等方式，降低系统复杂度带来的流失风险。

## 六、武器、职业与 Build 系统

### 6.1 武器设计方向

武器设计以真实武器为基础，进行复古朋克演绎。参考方向包括《原子之心》《无主之地》《Apex》等。

武器不应只是数值容器，而应承担以下功能：

- 体现世界观科技与时代审美；
- 支撑不同战斗距离与操作节奏；
- 与角色职业形成推荐搭配；
- 通过改枪和词条支持长线追求；
- 在视觉和音效上形成差异化爽感。

### 6.2 职业与角色关系

角色属于某个职业大类。职业适配推荐武器，但不完全限制玩家选择。

这样可以同时满足：

- 角色定位清晰；
- 商业化包装明确；
- Build 组合具有自由度；
- 深度玩家可以探索非标准搭配。

### 6.3 基础战斗流派

| 流派 | 定位 | 初步设计方向 |
|---|---|---|
| 突击步枪流 | 中庸稳定 | 以 M4、AK 等典型原型为基础，适合作为默认和新手流派。 |
| 喷子流 | 近距离爆发 | 弹丸散布、低射速、低弹匣，可扩展独头弹、燃烧弹、鸟弹、鹿弹等。 |
| 冲锋流 | 高射速近距离 | 强调移动压制、贴脸输出和连杀节奏。 |
| 射手 / 狙击流 | 远程精确 | 强调弱点打击、精英处理和 Boss 阶段输出。 |
| 召唤流 | 机器人联动射击 | 通过机器人、炮台、无人机等形成协同作战。 |

### 6.4 技能模组与状态设计

技能模组初步分为：

- 投掷类：爆发、控制、区域封锁；
- Buff 类：强化射击、换弹、移动、生存；
- 机动类：位移、闪避、脱战、追击。

Debuff 初步包括：

- 流血；
- 燃烧；
- 感电；
- 中毒。

元素反应可以考虑，但不宜过度数值化。理想效果是直观、可感知、能通过视觉和怪物行为理解，而不是主要依赖复杂公式。

## 七、内容规划

### 7.1 怪物设计

怪物应优先服务击杀爽感和暗黑式掉落可信度。

推荐方向：

- 肉质或胶质；
- 类人或动物；
- 现实物件与生物组织融合；
- 智械污染导致的畸变；
- 机械类占比受控，避免过多纯机械怪削弱射击反馈。

### 7.2 Boss 设计

Boss 设计建议采用“现实物件异常化”原则。

例如：

- 智械化冰箱；
- 失控游乐设施；
- 异常电视主播；
- 清洁机器人集群；
- 售票机 / 闸机系统；
- 乐园吉祥物；
- 度假小镇的公共服务系统。

Boss 的重点不是单纯巨大或科幻，而是让玩家感觉“这个东西本来应该属于日常生活，但现在变得危险、荒诞、不可控”。

### 7.3 关卡 Demo 方向

优先验证以下场景：

1. **朋克主题乐园**  
   天然具有关卡结构、视觉辨识度和首曝传播力，可呈现“明亮表皮下的腐坏”。

2. **电视台**  
   适合作为宣传主阵地，能展示世界观、AI 管理、社会控制和舆论包装。

3. **度假小镇**  
   可参考核弹小镇的背景逻辑，与世界观关键事件绑定，兼具生活感和危机感。

4. **微缩小镇**  
   适合展示人的气息、日常空间和异常尺度变化。

### 7.4 TTK 原则

TTK 参考《遗迹 2》，按普通小怪、精英、Boss 分层：

- 普通小怪：强调清理效率和死亡反馈；
- 精英怪：强调机制、压迫和短期战术调整；
- Boss：强调阶段变化、场景机制和掉落期待。

高难度更多应体现在伤害压力、走位要求、机制复杂度和容错率上，而不是简单增加血量，避免长时间刮痧造成无聊。

## 八、终局与长线运营

### 8.1 终局目标

项目希望形成具备长尾寿命的终局结构。初步目标为：

- 初始版本提供 100 小时以上的有效内容；
- 终局系统支撑 500 小时以上的长尾追求。

### 8.2 终局设计方向

可参考《流放之路 2》的终局设计，重点包括：

- 随机地图；
- 地图 Buff 随机；
- 掉落赌博感；
- 词条追求；
- 多角色养成驱动；
- 社交讨论和展示钩子。

### 8.3 单局时长

单局时长初步控制在 20 分钟左右，以 5 分钟为一个小节，每个小节提供精英怪、掉落或事件节点。

同时需要支持中途保存，以适配移动端低精力、碎片化和非连续游玩场景。

### 8.4 长线更新内容

长线更新主要包括：

- 新角色；
- 新地图；
- 新剧情；
- 新 Boss；
- 新武器与改装件；
- 新职业或职业分支；
- 新终局规则与赛季主题。

## 九、商业化设计

### 9.1 商业化原则

项目商业化应以角色厨力、外观、武器外观和轻量数值为主。

当前不建议重度依赖传统二游的强命座、强专武模式，原因包括：

- 不一定能保证商业化成功；
- 容易影响口碑；
- 可能破坏刷宝游戏中装备掉落和自由构筑的公平感；
- 会降低玩家通过刷图获得成长的满足感。

### 9.2 可商业化内容

初步可考虑：

- 角色外观；
- 武器外观；
- 主题套装；
- 职业幻想装扮；
- 特效外观；
- 轻量成长便利；
- 赛季通行证；
- 非强制性的收藏和展示内容。

### 9.3 商业化与玩法关系

商业化必须服务角色价值和长期表达，不应压倒刷宝循环。

理想状态是：

- 玩家因为角色而进入；
- 因为射击和掉落而留下；
- 因为 Build 和终局而长期游玩；
- 因为外观和表达而付费。

## 十、首曝 PV 方向

首曝 PV 的核心任务是建立项目定义、产品品质、角色厨力、战斗爽感和 Build 想象。

建议结构：

1. 主角团登场，建立角色标签；
2. 危机出现，呈现智械危机或乌托邦崩坏；
3. 切换战斗形态、装备和武器；
4. 重点展示武器改装；
5. 刷怪段落展示射击爽感；
6. 展示多种机制，保留解读空间；
7. Boss 战，突出现实物件异常化；
8. 暗黑式掉宝，初步展示养成体系；
9. 展示推荐装配，降低复杂感；
10. 多场景、多 Boss 穿梭混剪，拉开世界规模。

PV 需要避免只展示美术和角色，必须尽早建立“这是一个可以刷、可以掉、可以改、可以构筑”的玩法印象。

## 十一、团队核心能力需求

项目对团队能力的要求集中在五个方向：

| 能力方向 | 要求 |
|---|---|
| 概念与世界观 | 能建立复古朋克、暗黑微恐和风格化角色融合的稳定口径。 |
| 角色设计 | 能完成高标签角色的人设、形象、剧情故事和商业化表达。 |
| 射击刷图爽感 | 能设计枪械、命中反馈、怪物死亡、关卡节奏和 Boss 机制。 |
| 数值 Build | 能设计掉落、词条、技能、成长系统和终局循环。 |
| 商业化 | 能围绕角色、外观和武器表达设计低反感度付费内容。 |

## 十二、关键风险与验证计划

### 12.1 关键风险

| 风险 | 说明 | 验证方向 |
|---|---|---|
| 移动端刷宝需求不确定 | 移动端玩家是否愿意长期重复刷图仍需验证。 | 用研、买量测试、竞品观察。 |
| 二次元与刷宝融合风险 | 纯二游表达可能削弱暗黑掉落和击杀爽感。 | 以“风格化角色 + 暗黑微恐世界”做概念验证。 |
| TPS 枪感不足 | TPS 有利于角色露出，但枪感可能弱于 FPS。 | 验证开镜、命中、换弹、受击和死亡反馈。 |
| Build 复杂度过高 | 大 Build 库容易造成上手门槛。 | 默认流派、智能推荐、阶段化解锁。 |
| 商业化影响口碑 | 强数值付费可能破坏刷宝公平感。 | 以外观和轻量付费为主，控制数值边界。 |
| 美术融合失败 | 二游角色、暗黑微恐和复古朋克可能变成拼贴。 | 先建立统一艺术口径和一张 Demo 场景。 |

### 12.2 最小验证闭环

建议下一阶段优先完成一个最小可验证闭环：

- 一名高标签风格化角色；
- 一类武器流派，例如突击步枪或喷子；
- 一张主题乐园或电视台关卡；
- 一套基础掉落与 Build 组合；
- 一个现实物件异常化 Boss；
- 一段 60-90 秒核心体验视频或可交互 Demo；
- 一组用于买量 / 用研的概念素材。

该闭环的目标不是证明完整产品成立，而是验证：

- 角色是否有吸引力；
- 世界观是否有记忆点；
- TPS 刷怪是否爽；
- 掉落和 Build 是否有继续刷的欲望；
- 暗黑微恐与风格化角色是否能够融合。

## 十三、立项建议

基于当前内容，SPVE 具备继续推进立项论证的价值，但不建议直接进入完整产线投入。更合理的方式是进入概念验证阶段，围绕“风格化暗黑朋克 TPS 刷宝”建立最小闭环。

建议立项判断如下：

- **方向价值**：成立。角色驱动、PVE 刷宝、TPS 射击和复古朋克暗黑世界之间存在组合空间。
- **差异化**：有潜力。朋克主题乐园、异常物件 Boss、暗黑式掉落和二游角色商业化可以形成记忆点。
- **主要不确定性**：移动端刷宝需求、TPS 枪感、Build 复杂度、美术融合和商业化边界。
- **下一步建议**：不做大而全方案，优先做一条可体验、可展示、可测试的核心样板段。

最终建议：

> 项目可进入早期概念验证阶段。验证重点应聚焦于“风格化角色是否能带动暗黑微恐刷宝射击成立”，以及“移动端 TPS 刷图 + 掉落 Build 是否具备足够长期吸引力”。
