SPVE：风格化暗黑朋克刷宝射击

一个以角色商业化为外层驱动、以 TPS 刷宝射击为核心玩法、以复古朋克乌托邦崩坏为世界底盘的 PVE 长线项目。项目目标是在移动端友好的刷图循环中，结合强角色标签、枪械改装、Build 构筑、暗黑式掉落与高记忆点关卡。

1. 项目定位

SPVE 的核心机会在于：用二游擅长的角色标签与长线运营能力，承接刷宝游戏的重复游玩、装备掉落和 Build 深度。

角色负责吸引与留存，射击负责即时爽感，掉落与 Build 负责长线寿命，世界观负责差异化记忆点。
PVE TPS 刷宝 枪械改装 角色商业化 暗黑式掉落 复古朋克

平台判断

  • PC 仍以竞技游戏主导，更适合作为品质展示和手游补充，不宜重度押注。
  • 移动端需要验证是否存在“低精力消耗的刷刷刷”需求。
  • TPS 比 FPS 更有利于角色露出、人设联结和商业化，但需要补足枪感与开镜体验。

2. 世界观与概念风格

世界观方向以原子朋克和复古未来主义为基础，向美式朋克、中式朋克、欧洲朋克等主题扩展。为了避免抄袭风险，苏式朋克初期不作为主展示方向，可作为背景和侧面描写。

角色风格化 保留二游式角色标签、年代感、美感、个性和 Cos 欲望，避免同质化。
物件复古朋克 以真实生活物件为原型，进行智能化、智械化和朋克演绎。
世界反乌托邦 表层热血、燃、幽默，底层藏有人性黑暗和乌托邦崩坏。
怪物暗黑微恐 肉质、胶质、类人、动物与智械污染结合，机械类不宜占比过高。

反派与冲突

  • 反派方向参考《生化奇兵》：建立乌托邦，但乌托邦本身逐渐腐坏。
  • 世界中存在全球最强的 N 个 AI 智能，但领导它们的却是人类。
  • 核心矛盾不是单纯的智械暴走，而是人类借 AI、制度和乐园包装欲望。
建议内部风格口径：表皮明亮，底层腐坏；角色好看，世界不安全。

3. 核心玩法

玩法参考

  • 以《遗迹 2》为战斗与关卡体验蓝本。
  • 以《流放之路》为 Build 深度和终局设计参考。
  • 以《无主之地》《Apex》《原子之心》作为武器风格参考。

视角选择

  • 倾向 TPS，强化角色露出和商业化表达。
  • TPS 的代价是枪械枪感相较 FPS 会有折扣。
  • 动作流畅度和开镜手感仍能沉淀射击基础能力。

战斗循环

  1. 进入地图，选择角色、职业、武器与推荐 Build。
  2. 以 5 分钟为小节推进关卡，遭遇普通怪、精英怪和掉落节点。
  3. 通过射击、技能模组、道具和增强型大招形成战斗节奏。
  4. 击败 Boss 后获得暗黑式掉落，继续强化枪械、技能和角色构筑。
  5. 挑战更高难度、随机地图 Buff 和终局内容。

大招设计原则

可以存在强表现力大招，但不应像动作二游一样过度表演，也不能破坏射击与道具操作的重要性。大招更适合做成增强、异化射击或脱手道具，而不是纯播片灌伤害。

上手体验

  • 定位为易上手、难精通。
  • Build 库可以很大，但需要智能推荐搭配。
  • 参考三角洲的改枪推荐、金铲铲的阵容推荐。
  • 熟悉后允许玩家自行搭配，发挥 AI 分析推理优势。

4. 武器、职业与 Build 系统

Build 系统承担长线深度。角色绑定职业，职业适配推荐武器，但不完全限制，以避免角色和武器组合过早固化。

流派 战斗定位 设计要点 可扩展方向
突击步枪流 中庸稳定 M4、AK 等典型原型，适合作为新手默认流派。 精准、压枪、弹匣、元素弹药。
喷子流 近距离爆发 弹丸散布，低射速、低弹匣，强调距离判断。 独头弹、燃烧弹、鸟弹、鹿弹。
冲锋流 高射速近距离 移动压制、贴脸输出、机动操作。 吸血、过热、连杀加速。
射手 / 狙击流 远程精确 弱点打击、精英处理、Boss 阶段输出。 蓄力、穿透、标记、处决。
召唤流 机器人联动射击 通过机械伙伴、炮台或无人机制造协同输出。 召唤物改装、联动射击、自动索敌。

技能模组

投掷类

承担爆发、控制、区域封锁和怪群处理。

Buff 类

强化射击、换弹、移速、暴击或生存能力。

机动类

提供位移、闪避、脱战和地形应对能力。

Debuff 与元素反应

基础 Debuff 包括流血、燃烧、感电、中毒。元素反应可以做，但不要过度数值化，需要保持直观，让玩家能从视觉和行为上理解效果。

5. 关卡、怪物与 Boss

关卡应服务世界观展示和刷宝循环。更适合选择“本身就很关卡化”的空间：乐园、电视台、度假小镇、微缩小镇等。

关卡 Demo 方向

  • 朋克时代的迪斯尼或环球影城，可带有梦核感。
  • 电视台作为宣传主阵地，适合展示世界观。
  • 度假小镇参考核弹小镇背景，可与重要事件绑定。
  • 微缩小镇用于展示人的气息和世界生活感。

怪物方向

  • 肉质或胶质。
  • 类人或动物。
  • 机械类占比要少，否则击杀爽感会下降。
  • 可以通过智械污染连接肉感与机械感。

Boss 设计

Boss 以现实物品为原型，进行智能化、智械化和异常化。重点是“不因过分科幻而失去代入”。例如冰箱、游乐设施、电视主播、清洁机器人、售票机、吉祥物等，都可以成为关卡机制与 Boss 表现的来源。

TTK 原则

  • 参考《遗迹 2》，按普通小怪、精英、Boss 分层设计。
  • 高难度更多体现在伤害和容错压力上。
  • 避免因为输出不足而长时间刮痧，导致刷图无聊。

6. 终局与长线

长线目标是用随机、赌博感、地图 Buff 和多角色养成支撑持续刷图。

内容更新

  • 新角色
  • 新地图
  • 新剧情

终局设计

  • 参考《流放之路 2》
  • 赌与随机
  • 地图 Buff 随机
  • 社交钩子

时长目标

  • 单局约 20 分钟
  • 5 分钟一个小节
  • 可保存
  • 初始 100h，终局 500h

深渊设计

可以有深渊，但形式需要重新设计。它不应只是传统爬塔或数值验收，而要继续服务多角色养成、Build 变化和长线掉落。

7. 商业化方向

商业化以角色厨力和外观为主，搭配微数值。项目不宜重走强命座、强专武的路径，因为这类方式不一定保证商业化成功，也可能影响口碑。

可售卖内容

  • 角色外观。
  • 武器外观与武器主题演绎。
  • 职业幻想相关装扮。
  • 轻量数值或便利型内容需谨慎。

商业化基础

  • 角色需要有年代感、美、个性和 Cos 欲望。
  • 角色和职业绑定，但武器不完全限制。
  • 战斗中角色出场频率高，TPS 更利于外观价值感。

8. 首曝 PV 思路

首曝 PV 的任务是同时建立游戏定义、产品品质、角色厨力、战斗爽感和 Build 想象。

主角团登场，建立角色标签与队伍气质。
危机出现：智械危机或乌托邦设施失控。
切换战斗形态、装备、武器，展示 TPS 角色露出。
重点展示武器改装，建立枪械差异化。
刷怪段落重点展示爽感，立住玩法第一印象。
展示多种机制，留给高参与玩家解读空间。
Boss 战：现实物件异常化，强化记忆点。
暗黑式掉宝，初展养成体系，并展示推荐装配降低复杂感。
更多场景与 Boss 穿梭混剪，拉开世界规模。

9. 团队核心能力

概念与世界

概念设计、美术风格设计、世界观搭建。

角色设计

人设、形象、剧情故事，以及角色商业化表达。

射击刷图爽感

枪械、关卡、怪物、TTK 和 Boss 机制。

数值 Build

10. 风险与验证问题

问题 风险 验证方式
移动端是否存在刷宝需求 如果低精力刷图需求不成立，核心循环可能不适配移动端。 用研、买量测试、竞品观察：逆战手游、二重螺旋等。
二次元与刷宝是否能融合 纯二游气质可能削弱暗黑掉落和怪物击杀爽感。 用“风格化角色 + 暗黑微恐世界”做概念验证。
TPS 枪感是否足够 角色露出增强，但射击手感可能弱于 FPS。 优先验证开镜、命中反馈、换弹、枪械节奏。
Build 复杂度是否过高 流放之路式深度可能造成新手流失。 智能推荐搭配、默认流派、阶段化解锁。
商业化是否影响口碑 强命座、强专武可能破坏刷宝公平感。 优先验证外观、武器皮肤和轻量数值边界。
下一阶段建议聚焦一个最小闭环：一名高标签角色、一类武器流派、一张主题乐园关卡、一套掉落 Build、一个现实物件异常化 Boss。
