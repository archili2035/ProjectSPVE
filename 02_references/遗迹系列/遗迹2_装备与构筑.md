# 遗迹2装备与构筑

资料状态：第一版  
资料采集日期：2026-06-30  
研究对象：《Remnant II》装备、武器模组、突变因子、戒指、项链、遗物、特性与构筑模式  
用途：为当前“角色驱动的 PVE 刷宝射击二游”提供装备构筑层面的参考。

---

## 1. 本文档定位

本文档不是《遗迹2》装备数据库，而是第一版“装备与构筑设计研究”。

当前目标：

1. 先看清《遗迹2》的装备构筑层级。
2. 找出哪些装备层真正改变玩法。
3. 抽取代表性样本，而不是全量搬运条目。
4. 归纳可转译到本项目的设计模式。
5. 为后续全量资料表建立字段和方向。

一句话判断：

> 《遗迹2》的装备系统价值，不在于单件装备数值有多复杂，而在于它把“枪械节奏、主动模组、被动突变因子、戒指/项链拼图、遗物触发、特性成长”拆成多层，让玩家可以围绕一个战斗条件搭出不同 Build。

## 2. 装备系统总览

《遗迹2》的构筑大致由以下层级组成：

| 层级 | 作用 | 构筑价值 |
| --- | --- | --- |
| Archetype / 职业 | 决定基础战斗定位、主动技能、团队被动和职业特性。 | 提供角色/职业身份。 |
| Weapons / 武器 | 分为长枪、手枪、近战；决定射击或近战节奏。 | 决定基础手感与输出结构。 |
| Weapon Mods / 武器模组 | 标准模组可装在普通远程武器上；特殊武器自带不可拆模组。 | 提供主动技能、元素、控制、召唤、治疗和爆发。 |
| Mutators / 突变因子 | 装在武器上的被动改造，分远程和近战，升级后强化效果。 | 调整输出循环、资源循环或触发条件。 |
| Rings / 戒指 | 数量最多的被动拼图片。 | 细化流派、触发条件、风险收益和资源循环。 |
| Amulets / 项链 | 通常更强、更核心的单件构筑装备。 | 决定流派主轴或关键循环。 |
| Relics / 遗物 | 战斗中使用的治疗/防御/资源道具。 | 同时承担生存和触发器功能。 |
| Traits / 特性 | 被动属性成长，有点数上限。 | 提供长期成长和流派底座。 |
| Armor / 防具 | 提供护甲、重量和抗性。 | 更偏防御、负重和抗性管理，构筑存在感弱于饰品。 |

### 2.1 武器分类

根据 Remnant2 Wiki，武器分为三个槽位：

- Long Guns / 长枪
- Handguns / 手枪
- Melee Weapons / 近战武器

远程武器又区分为：

| 类型 | 特点 |
| --- | --- |
| Standard Weapons | 普通武器，可安装可替换 Weapon Mod。 |
| Special Weapons | 特殊武器，自带不可拆卸的专属 Weapon Mod。 |

这点很重要：

> 普通武器提供“枪械节奏 + 可替换技能槽”，特殊武器提供“枪械节奏 + 固定玩法身份”。

对本项目来说，这可以转译成：

- 普通枪械：允许玩家装配战术模块。
- 专属枪械：自带强机制，可能绑定 Boss 材料、角色专武或活动奖励。

## 3. 构筑层级拆解

可以把《遗迹2》的装备构筑理解为六层：

```text
职业 / Archetype
  决定技能、被动、职业身份

武器 / Weapons
  决定射击节奏、距离、弹匣、弱点倍率、暴击、手感

武器模组 / Weapon Mods
  决定主动能力：元素、控制、治疗、召唤、护盾、爆发

突变因子 / Mutators
  决定武器被动：暴击、弱点、Mod、状态、弹药、护盾、近战循环

戒指 + 项链 / Rings + Amulets
  决定 Build 拼图：触发条件、伤害来源、资源循环、风险收益

遗物 + 特性 / Relics + Traits
  决定生存、触发器、冷却、Mod Power、技能持续、恢复能力
```

这套结构最值得注意的是：

- 武器不是唯一 Build 来源。
- 职业不是唯一角色定位来源。
- 戒指/项链不是单纯数值，而是大量条件触发器。
- 遗物不只是回血，也可以是 Mod Power、护盾、闪避、生命转换和技能冷却工具。
- 突变因子让同一把武器可以服务不同流派。

## 4. 武器：射击节奏与专属身份

### 4.1 武器属性维度

远程武器页面常见字段包括：

| 字段 | 设计意义 |
| --- | --- |
| RPS | 射速，决定持续输出节奏。 |
| Magazine | 弹匣容量，影响换弹频率和弹匣触发类效果。 |
| Ammo | 总备弹，影响续航。 |
| Damage | 单发伤害和升级成长。 |
| Ideal Range | 理想射程，影响武器站位。 |
| Falloff Range | 衰减距离，影响远距离表现。 |
| Crit | 暴击倾向。 |
| Weakspot | 弱点收益。 |
| Stagger | 硬直能力。 |
| Built-in Mod | 特殊武器专属玩法身份。 |

### 4.2 代表性武器样本

| 武器 | 类型 | 效果/特点摘要 | 构筑倾向 | 设计价值 |
| --- | --- | --- | --- | --- |
| Blackmaw AR-47 | 标准长枪 | 稳定全自动步枪，基础性能均衡。 | 通用远程、暴击、持续输出。 | 适合作为基准枪，用来衡量其他武器节奏差异。 |
| Nightfall | 特殊长枪 | 自带 Dreadwalker，可进入梦魇状态，强化射速、吸血和弹药体验。 | 爆发、生存、持续压制。 | 特殊武器通过内置模组形成强身份。 |
| Merciless | 特殊长枪 | 和流血/穿透相关，适合状态持续伤害。 | 流血、状态、穿透。 | Boss 路线奖励可以直接定义流派。 |
| Sagittarius | 特殊长枪/弓 | 弓类蓄力节奏，自带 Starfall。 | 弱点、蓄力、Mod 混合。 | 武器输入节奏本身可以成为构筑差异。 |
| Enigma | 特殊手枪 | 链电/过载，擅长清杂。 | 电击、AOE、清场。 | 副武器也可以承担一类明确战术职责。 |
| Star Shot | 特殊手枪 | Big Bang 爆炸蓄力，火焰/爆发倾向。 | 爆炸、燃烧、蓄力。 | 小武器可以提供高辨识度爆发按钮。 |
| Sporebloom | 特殊长枪/霰弹 | 近距离高爆发，自带 Spore Shot。 | 近战射击、爆发、硬直。 | 距离风险可以换取高收益。 |

### 4.3 对本项目的启发

1. 武器需要有“节奏身份”，不是只区分伤害数字。
2. 普通武器可以开放插件槽，专属武器可以自带不可拆机制。
3. 副武器也可以是战术工具，不一定只是备用输出。
4. 武器来源可以绑定 Boss、谜题、隐藏事件，强化刷宝目标。
5. 弱点、射程、换弹、弹匣、蓄力、过热都可以成为构筑条件。

## 5. Weapon Mods：枪械上的主动能力层

### 5.1 模组分类

Weapon Mods 大致分三类：

| 类型 | 说明 |
| --- | --- |
| Swappable Mods | 可替换模组，装在普通远程武器上，需要 Mod Power 释放。 |
| Attached Ranged Mods | 特殊远程武器自带，不可拆。 |
| Melee Intrinsic Abilities | 近战武器内置能力，通常不消耗 Mod Power。 |

### 5.2 代表性 Weapon Mods

| 模组 | 类型 | 效果摘要 | 支持流派 | 设计价值 |
| --- | --- | --- | --- | --- |
| Hot Shot | 可替换 | 火焰弹药，增加远程伤害并施加 Burning。 | 燃烧、元素、早期输出。 | 用简单方式让普通枪临时转元素流。 |
| Corrosive Rounds | 可替换 | 酸蚀弹药，提升暴击倾向并施加 Corroded。 | 酸蚀、暴击、破防。 | 状态和暴击可以绑定。 |
| Overflow | 可替换 | 电击弹药，提升射速/换弹并施加 Overloaded。 | 电击、射速、清场。 | 元素模组也能改变枪械手感。 |
| Healing Shot | 可替换 | 发射治疗弹，治疗自己或队友。 | 治疗、合作、支援。 | 枪械模组可以承担支援职责。 |
| Shielding Shot | 可替换 | 为目标提供护盾。 | 护盾、团队支援。 | 枪械可成为“远程保护工具”。 |
| Firestorm | 可替换 | 火焰旋风，聚怪并造成燃烧。 | AOE、控制、燃烧。 | 模组可同时承担伤害与控场。 |
| Rootlash | 可替换 | 召唤 Root Tentacles，攻击并偷取生命。 | 召唤、吸血、持续输出。 | 模组可以提供临时召唤物。 |
| Song of Eafir | 可替换 | 范围减速/削弱敌人输出。 | 控制、生存、团队。 | 控制型模组适合高难战斗。 |

### 5.3 对本项目的启发

Weapon Mods 很适合转译为：

- 枪械插件
- 战术模块
- 技能弹药
- 异常弹匣
- 支援技能载体

关键不是“多一个技能按钮”，而是让枪械拥有临时角色：

| 模组方向 | 本项目可转译 |
| --- | --- |
| 元素弹药 | 异常属性弹匣 / 状态弹种 |
| 治疗弹 | 支援角色远程治疗技 / 医疗弹 |
| 护盾弹 | 远程护盾投射 / 防护模块 |
| 召唤物 | 炮台 / 无人机 / 异常实体召唤 |
| 控场 | 减速场 / 引力场 / 封锁区 |
| 爆发 | Boss 材料武器的专属技能 |

## 6. Mutators：武器被动改造层

### 6.1 系统特点

Mutators 分为远程和近战两类。根据 Wiki 页面，当前页面列出 66 个 Mutators：

- Ranged Mutators：41 个。
- Melee Mutators：25 个。

它们通常有两个特点：

1. 基础效果随升级增强。
2. 10 级获得额外特殊效果。

这使 Mutator 不只是“小词条”，而是武器构筑方向选择。

### 6.2 代表性 Mutators

| Mutator | 类型 | 效果摘要 | 支持流派 | 设计价值 |
| --- | --- | --- | --- | --- |
| Momentum | 远程 | 暴击后叠加暴击率和暴击伤害。 | 暴击、连射。 | 让高射速武器形成滚雪球。 |
| Ghost Shell | 远程 | 连续弱点命中后获得额外伤害。 | 弱点、精准射击。 | 鼓励稳定命中弱点。 |
| Bandit | 远程 | 有概率把弹药返还到弹匣，10 级后返还弹药提升射速。 | 持续射击、弹药经济。 | 让弹匣/续航成为构筑主题。 |
| Failsafe | 远程 | 增加 Mod 伤害，10 级可能不消耗充能。 | Mod 爆发。 | 直接强化主动模组循环。 |
| Harmonizer | 远程 | 增加 Mod 伤害，并帮助副武器生成 Mod Power。 | 双武器 Mod。 | 鼓励主副武器循环。 |
| Twisting Wounds | 远程 | 对流血目标增伤，10 级可通过弱点/暴击施加流血。 | 流血、状态。 | 触发条件与状态自循环结合。 |
| Searing Wounds | 远程 | 对燃烧目标增伤，10 级可通过弱点/暴击施加燃烧。 | 燃烧、状态。 | 和火焰模组/装备形成组合。 |
| Shielded Strike | 近战 | 近战获得护盾，蓄力伤害可随护盾增强。 | 护盾、近战。 | 把防御资源转成进攻资源。 |
| Weaponlord | 近战 | 普攻强化下一次蓄力攻击，10 级可使蓄力暴击。 | 近战爆发。 | 建立普攻-蓄力循环。 |

### 6.3 对本项目的启发

Mutator 这一层非常适合转译成“武器芯片”或“枪械被动模块”：

- 不改变角色，不改变武器基础模型，但改变武器循环。
- 可以让同一把枪适配不同角色/流派。
- 适合承担刷宝深度，因为它比武器本体更容易做大量横向变化。

设计上尤其值得借鉴：

1. **10 级质变点**：升级到满级后获得额外机制，而不是只加数值。
2. **条件自循环**：例如弱点/暴击施加状态，状态再带来增伤。
3. **资源转化**：弹药、护盾、Mod Power、灰血、技能冷却之间互转。
4. **武器类型适配**：蓄力武器、连射武器、单发武器、近战武器需要不同被动。

## 7. Rings 与 Amulets：Build 拼图核心

### 7.1 Rings / 戒指

Remnant2 Wiki 的 Rings 页面列出大量戒指。页面采集结果显示当前列表约 225 个戒指，覆盖几乎所有构筑方向。

戒指常见功能：

- 全伤害、远程、近战、技能、Mod、元素、爆炸伤害。
- 暴击率、暴击伤害、弱点伤害。
- 状态伤害、状态持续、状态扩散。
- 护盾、Bulwark、减伤、护甲、生命上限。
- 生命恢复、灰血、吸血、治疗效率。
- 技能冷却、技能伤害、Mod Power、Mod 需求。
- 换弹、射速、弹药、后坐力、散布、蓄力速度。
- 召唤物伤害、召唤物吸血、召唤物防御。
- 合作支援、复活、团队承伤。

项链常见功能：

- 状态/元素流核心。
- 护盾/Bulwark 核心。
- Relic 触发核心。
- Mod/Skill 轮转核心。
- 低血/灰血风险收益核心。
- 远程、近战、换弹、射速核心。
- 召唤流核心。

### 7.5 对本项目的启发

戒指/项链这一层非常适合转译为：

- 遗物
- 异常物
- 战术挂件
- 角色外部构筑件
- 小件装备词条

关键设计原则：

1. **小件装备不要只加数值，要提供条件。**
2. **项链/核心遗物可以定义流派，戒指/小件负责拼图。**
3. **风险收益要可读：低血、缩短射程、禁用弱点、牺牲治疗等。**
4. **防御资源可以转进攻，但要防止形成无脑最优解。**
5. **探索/经济装备可以存在，但不要挤占战斗构筑核心。**

## 8. Relics 与 Traits：生存、触发器和长期底座

### 8.1 Relics / 遗物

遗物是战斗中使用的道具，但《遗迹2》让遗物承担了很多非治疗功能。

代表性遗物：

| 遗物 | 效果摘要 | 支持流派 | 设计价值 |
| --- | --- | --- | --- |
| Dragon Heart | 快速治疗。 | 基础生存。 | 标准治疗基准。 |
| Runed Heart | 提供生命恢复，并为两把武器生成 Mod Power。 | Mod、续航。 | 治疗道具变成资源工具。 |
| Shielded Heart | 获得等同最大生命的护盾。 | 护盾、生存。 | 直接服务护盾构筑。 |
| Siphon Heart | 一段时间内获得吸血。 | 持续输出、生存。 | 输出越高，生存越强。 |
| Reprocessed Heart | 将生命转化为灰血，并持续生成 Mod Power。 | 高风险 Mod。 | 用生命风险换主动资源。 |
| Quilted Heart | 不提供标准治疗，期间免除耐力消耗并让闪避回血。 | 闪避、生存。 | 将闪避行为变成恢复机制。 |
| Diverting Heart | 不提供标准治疗，持续降低技能冷却。 | 技能流。 | 遗物可以成为技能循环工具。 |
| Bloodless Heart | 快速使用，短时间几乎免伤护盾。 | 高压生存。 | 提供短窗口防御，但不能防即死。 |

### 8.1.1 遗物的养成与获取路径

遗物的"养成"分四层，其中真正涉及数值升级的是充能次数和碎片品质，遗物本体与棱镜更多是横向换装与终局成长：

| 养成维度 | 方式 | 成本 / 来源 | 说明 |
| --- | --- | --- | --- |
| 遗物本体 | 横向换装 | 世界主线、Boss、隐藏事件、商人、DLC | 同时只能装备 1 个，默认龙心；本质是换流派而非单件数值升级。 |
| 充能次数 | 数值升级 | Wallace：拟像 Simulacrum ×1 + Lumenite 水晶 ×10 + 废料 Scrap ×1000 | 初始 3 充能，每次 +1；世界石休息补满；拟像每世界约 1 个，是全局最稀缺材料之一。 |
| 遗物碎片 | 词条养成 | 强敌 / Boss / 宝箱掉落；Dwell 购买或合成（遗物粉尘 Relic Dust + 废料） | 每遗物 3 个碎片槽，红=伤害、蓝=防御、黄=功能；3 个同级碎片合成 1 个更高品质。 |
| 棱镜 Prism | 终局成长 | 随 XP 升级，投入碎片影响随机结果 | 《The Dark Horizon》后加入，独立于遗物本体；Fusion 合并槽位、满级 Legendary Bonus。 |

碎片品质梯度：**裂片 → 普通 → 坚固 → 抛光 → 华丽 → 神话**，品质上限受难度档位与总职业等级（Power Level）影响。

对本项目的转译：

- "换装不同遗物" → 角色战术道具 / 异常稳定器的横向换装。
- "Wallace 提充能" → 用拟像类稀缺材料做长线成长卡点，制造稀缺感而非纯数值堆叠。
- "碎片合成" → 词条 / 模块的低成本重置与定向合成，降低试错成本。
- "棱镜" → 可作为角色终局 / 赛季长期养成的独立目标，而非绑定单件装备。

遗物的关键价值：

- 它不是单纯“回血瓶”。
- 它可以成为 Build 的触发按钮。
- 它可以把治疗窗口、输出窗口和资源窗口绑定。

对本项目来说，可以参考为：

- 战术药剂
- 异常稳定器
- 护盾发生器
- 支援角色急救技
- 角色爆发前置触发器

### 8.2 Traits / 特性

Traits 是被动成长。Wiki 页面说明：

- 每个 Trait 最高 10 级。
- 点数有上限；《The Awakened King》后 Trait Point Cap 为 85。
- 核心特性包括 Vigor、Endurance、Spirit、Expertise。
- 职业特性可通过职业升级解锁，职业 10 级后可被其他构筑使用。
- 可用 Orb of Undoing 重置。

代表性特性：

| 特性 | 效果方向 | 支持流派 |
| --- | --- | --- |
| Vigor | 最大生命。 | 通用生存。 |
| Endurance | 最大耐力。 | 闪避、近战。 |
| Spirit | Mod Power 生成。 | Mod 流。 |
| Expertise | 技能冷却。 | 技能流。 |
| Longshot | 武器理想射程。 | 远程、弱点。 |
| Handling | 后坐力/散布。 | 射击手感。 |
| Flash Caster | Mod 和 Skill 施法速度。 | 高频主动能力。 |
| Fortify | 护甲效果。 | 重甲、坦克。 |
| Triage | 治疗效率。 | 医疗、支援。 |
| Regrowth | 生命恢复。 | 召唤/持续生存。 |
| Rugged | 召唤物生命。 | 召唤。 |
| Barkskin | 减伤。 | 坦克、生存。 |
| Affliction | 状态持续时间。 | 状态流。 |

### 8.3 对本项目的启发

Traits 可转译为：

- 账号级/角色级被动成长。
- 职业熟练度奖励。
- 角色突破后可外借的被动模块。
- 长期成长但不决定全部 Build 的底座。

但要注意：

- 如果全是小数值，玩家感知弱。
- 应该在关键等级提供机制变化或明显节点。
- 重置成本要低，否则玩家不愿尝试 Build。

## 9. Armor：防御、重量和抗性

《遗迹2》的防具主要提供：

- Armor / 护甲值。
- Weight / 重量。
- Bleed、Fire、Shock、Corrosive、Blight 等抗性。
- 负重与闪避表现相关。

采集资料中未看到防具有类似前作那样强套装效果的构筑核心地位。它更像防御与负重管理层。

设计观察：

| 方向 | 说明 |
| --- | --- |
| 轻甲 | 护甲低，但单位重量效率较高，更适合机动。 |
| 重甲 | 总护甲高，但重量高，机动代价更大。 |
| 抗性 | 面对特定状态/区域时有价值。 |
| DR 上限 | 总减伤存在上限，防止无限堆减伤。 |

对本项目的启发：

- 防具如果没有套装效果，就主要服务生存和外观。
- 如果本项目需要装备刷宝深度，防具最好不要只是防御数值。
- 可以考虑将“防具/护甲”改造成角色外观和抗性为主，把流派核心放在遗物、模组、词条上。

## 10. 初步构筑模式归纳

### 10.1 弱点 / 暴击流

核心条件：

- 命中弱点。
- 暴击触发。
- 连续命中保持叠层。

代表组件：

- Zania's Malice
- Probability Cord
- Ring of Flawed Beauty
- Momentum
- Ghost Shell
- Hunter 类职业特性/远程特化

设计价值：

> 把射击操作水平直接转化为 Build 收益。

对本项目参考：

- 精准射击角色。
- 弱点暴击遗物。
- 连续弱点命中奖励。
- 错失弱点会掉收益，形成操作压力。

---

### 10.2 Mod Power / 主动模组流

核心条件：

- 生成 Mod Power。
- 降低 Mod 需求。
- 提高 Mod 伤害。
- 使用 Mod 后触发额外效果。

代表组件：

- Spirit
- Runed Heart
- Cataloger's Jewel
- Golden Ribbon
- Failsafe
- Harmonizer
- Feedback

设计价值：

> 把枪械输出转化为主动能力循环，避免射击只是普攻。

对本项目参考：

- 枪械插件能量条。
- 战术模块充能。
- 使用技能后强化射击，或射击后加速技能。

---

### 10.3 技能冷却 / 职业技能流

核心条件：

- 降低技能冷却。
- 增加技能持续时间。
- 增加技能充能次数。
- 技能使用后触发增益。

代表组件：

- Expertise
- Legacy Protocol
- Silver Ribbon
- Hyperconductor
- Diverting Heart
- Flash Caster

设计价值：

> 让职业技能成为流派主轴，而不只是冷却好了就按。

对本项目参考：

- 主控角色技能循环。
- 支援角色技能 CD 构筑。
- 技能持续/充能/冷却三角关系。

---

### 10.4 召唤流

核心条件：

- 召唤物数量。
- 召唤物吸血。
- 召唤物提供防御或伤害。
- 召唤物死亡/进入战场触发效果。

代表组件：

- Soul Guard
- Soul Link
- Soul Shard
- Conjurer's Circle
- Rugged
- Blood Bond
- Rootlash

设计价值：

> 召唤物不只是额外伤害，也能成为防御、回血和触发源。

对本项目参考：

- 炮台角色。
- 无人机支援角色。
- 召唤物承伤、治疗、触发队伍被动。

---

### 10.5 护盾 / Bulwark 流

核心条件：

- 获得护盾。
- 有护盾时触发回血/增伤/暴击。
- Bulwark 层数转化为减伤或输出。

代表组件：

- Shielded Heart
- Generating Band
- Difference Engine
- Energy Diverter
- Whispering Marble
- Dried Clay Ring
- Shielded Strike

设计价值：

> 防御资源可以成为进攻资源，让坦克流也有输出表达。

对本项目参考：

- 护盾反击角色。
- 防御转火力遗物。
- 支援角色给盾后触发主 C 输出窗口。

---

### 10.6 状态 / 元素流

核心条件：

- 施加 Burning、Bleeding、Corroded、Overloaded 等状态。
- 对带状态目标增伤。
- 状态应用时触发爆炸或扩散。
- 多种状态叠加收益。

代表组件：

- Hot Shot
- Corrosive Rounds
- Overflow
- Twisting Wounds
- Searing Wounds
- Chains of Amplification
- Energized Neck Coil
- Ahanae Crystal

设计价值：

> 状态不是附赠伤害，而是下一步输出循环的门槛。

对本项目参考：

- 异常元素体系。
- 角色负责上异常，枪械/遗物负责消耗异常。
- 多角色支援形成异常组合。

---

### 10.7 低血 / 灰血风险收益流

核心条件：

- 低血提高伤害。
- 灰血存在时提高伤害/减伤。
- 限制治疗上限换收益。
- 生命转化为资源。

代表组件：

- Vengeance Idol
- Death's Embrace
- Restriction Cord
- Amber Moonstone
- Reprocessed Heart
- Canine Keepsake
- Effigy Pendant

设计价值：

> 明确风险换高收益，适合高熟练玩家。

对本项目参考：

- 压血输出角色。
- 受击积累灰血资源。
- 护盾替代治疗的高风险玩法。

---

### 10.8 换弹 / 射速 / 弹药经济流

核心条件：

- 换弹后增益。
- 弹匣越空/越满收益不同。
- 弹药返还。
- 射速和装填速度联动。

代表组件：

- Bandit
- Extender
- Lithely
- Gunslinger's Charm
- Gunslinger's Ring
- Overflow
- Deep Pocket Ring

设计价值：

> 让射击基础动作本身成为 Build 条件。

对本项目参考：

- 换弹爆发角色。
- 弹匣管理流。
- 高射速压制流。
- 弹药/热量/过载作为资源系统。

---

### 10.9 探索 / 经济流

核心条件：

- 增加 Scrap 或材料收益。
- 自动拾取材料。
- 增加移动效率。
- 降低探索损耗。

代表组件：

- Scavenger's Bauble
- Explorer 相关特性/玩法
- 移动速度与拾取类装备

设计价值：

> 刷宝游戏不只有战斗 Build，也有刷图效率 Build。

对本项目参考：

- 日常刷图配装。
- 探索/采集角色价值。
- 非战斗支援角色也能参与长期循环。

## 11. 对本项目的可转译设计模式

### 11.1 三层核心构筑建议

结合当前项目方向，可以转译为：

```text
角色
  决定战斗机制、商业化入口、技能身份和队伍定位。

枪械 / 武器
  决定射击手感、距离、弹匣、换弹、弱点收益和基础输出节奏。

遗物 / 模组 / 词条
  决定构筑变化、刷宝深度、触发条件和流派分化。
```

### 11.2 可直接参考的设计模式

| 遗迹2设计 | 本项目可转译 |
| --- | --- |
| Standard Weapon + Swappable Mod | 普通枪械 + 可替换战术模块。 |
| Special Weapon + Attached Mod | 专属武器 / Boss 武器 / 角色专武。 |
| Mutator | 枪械芯片 / 被动模块 / 武器专精插件。 |
| Rings | 小件遗物 / 异常物 / 条件词条拼图。 |
| Amulet | 流派核心遗物 / 核心异常物。 |
| Relic | 战术药剂 / 异常稳定器 / 支援触发器。 |
| Trait | 角色熟练度 / 职业被动 / 长期成长节点。 |
| Boss Material Weapon | Boss 专属制造与目标刷取。 |
| Hidden Gear | 隐藏异常物 / 隐藏模块 / 社区传播内容。 |

### 11.3 特别适合当前项目的流派方向

优先验证这些：

1. **弱点暴击流**  
   适合验证 TPS 射击价值。

2. **换弹爆发流**  
   适合把射击动作节奏做成 Build。

3. **元素异常流**  
   适合二游角色属性体系和多角色支援。

4. **召唤炮台流**  
   适合支援角色、无人机、部署物设计。

5. **护盾反击流**  
   适合防御型角色也有输出表达。

6. **技能/Mod 循环流**  
   适合角色技能和枪械模块互相转化。

7. **低血高压流**  
   适合高熟练玩家，但不应作为新手主路径。

## 12. 需要规避的问题

### 12.1 不要把复杂度一次性砸给玩家

《遗迹2》装备很多，但它面向的是愿意查 Wiki、试 Build 的核心玩家。二游用户不一定接受同等信息密度。

建议：

- 前期只开放少量关键词。
- 给每个角色提供推荐流派。
- 装备详情里解释“为什么适合这个角色”。
- 提供低成本重置和训练场验证。

### 12.2 不要让小数值被动成为主要乐趣

如果装备只是 `+3%`、`+5%`、`+10%`，感知会弱。

建议：

- 关键装备要有条件或机制。
- 满级/突破节点提供质变。
- 小词条负责微调，核心遗物负责玩法变化。

### 12.3 隐藏装备不要卡核心成长

遗迹系列喜欢隐藏内容，这是优点，但如果核心流派关键件过度隐藏，会导致攻略依赖。

建议：

- 隐藏内容奖励横向玩法、外观、特殊流派。
- 主流构筑核心件应有可追踪目标。
- 提供定向刷取、保底或线索系统。

### 12.4 防御转输出要谨慎

护盾/Bulwark 转伤害很有趣，但如果数值过强，容易形成所有人都堆防御的最优解。

建议：

- 防御转输出应有条件、窗口或上限。
- 让不同流派各有优势场景。

## 14. 当前结论

《遗迹2》装备与构筑系统最值得本项目学习的点是：

> 把“角色/职业身份”和“装备构筑自由”拆开。角色决定战斗方向，装备负责让这个方向出现多个变体。

对当前项目来说，比较稳的吸收方式是：

1. 角色负责商业化、技能身份和情感连接。
2. 枪械负责射击手感和基础输出节奏。
3. 模组/遗物/词条负责长期刷宝和流派分化。
4. Boss 与战区负责掉落目标。
5. 赛季/活动负责引入临时规则和新构筑件。

不建议照搬《遗迹2》的角色弱存在感，也不建议把核心玩法藏在大量 Wiki 和隐藏条件里。我们要借的是“装备如何改变打法”，不是“玩家必须查表才能玩”。
