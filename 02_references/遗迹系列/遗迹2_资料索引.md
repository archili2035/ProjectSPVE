## 1. 文档用途

本文档用于沉淀《遗迹2》的可回查资料入口，后续所有装备、技能、职业、Boss、DLC 与系统拆解都优先从这里建立引用链。

当前不追求一次性搬运全量数据，优先建立：

1. 可信资料源。
2. 系统分类目录。
3. 后续可抽取字段。
4. 与本项目设计讨论相关的优先级。

## 2. 资料源优先级

### 2.1 主数据源：Remnant2 wiki.gg

- 入口：<https://remnant2.wiki.gg/>
- 用途：作为后续装备、职业、DLC、Boss、地点和系统资料的主数据源。
- 优点：结构较清晰，适合按分类抽取。
- 注意：具体数值仍需和其他来源交叉校验。

重点分类：

- Weapons
- Long Guns
- Hand Guns
- Melee Weapons
- Weapon Mods
- Mutators
- Archetypes
- Skills
- Perks
- Traits
- Rings
- Amulets
- Relics
- Armor
- Bosses
- Locations
- DLC

### 2.2 辅助数据源：Remnant Wiki

- 入口：<https://remnant.wiki/>
- 用途：补充机制解释、职业页面、地点和事件说明。
- 优点：部分页面对机制和来源描述较细。
- 注意：页面格式不完全统一，适合辅助校验，不建议作为唯一来源。

### 2.3 补充数据源：Fextralife

- 入口：<https://remnant2.wiki.fextralife.com/>
- 用途：补充装备、戒指、项链、职业、特性等列表。
- 优点：覆盖面广，搜索命中率高。
- 注意：页面质量和更新状态需要校验，不作为主数据源。

### 2.4 官方资料

- Remnant II 官网：<https://www.remnantgame.com/>
- Remnant II Steam：<https://store.steampowered.com/app/1282100/REMNANT_II/>
- Arc Games 新闻：<https://www.arcgames.com/>
- Gunfire Games 更新说明：<https://gunfiregames.com/>

用途：

- 确认官方系统定位。
- 确认 DLC 内容边界。
- 确认大版本新增系统，例如 Boss Rush、Prism、Archetype。
- 提供对外引用时更稳的出处。

## 5. 后续数据抽取字段

### 5.1 装备字段

| 字段 | 说明 |
| --- | --- |
| 名称 | 英文名；如有可靠中文译名再补中文名。 |
| 类型 | 长枪、手枪、近战、戒指、项链、遗物、防具、模组、突变因子。 |
| 来源 | Boss、事件、商人、隐藏、随机掉落、DLC。 |
| 效果 | 原始效果描述。 |
| 触发条件 | 暴击、弱点、换弹、使用技能、Mod、低血量、满血等。 |
| 影响对象 | 远程、近战、技能、Mod、召唤、治疗、护盾、异常。 |
| 构筑倾向 | 暴击流、弱点流、召唤流、技能流、Mod流、坦克流、治疗流等。 |
| 设计价值 | 对本项目的参考意义。 |
| 风险 | 隐藏过深、数值感弱、依赖特定组合、理解成本高等。 |
| 来源链接 | Wiki / 官方 / 评测链接。 |

### 5.2 职业字段

| 字段 | 说明 |
| --- | --- |
| 职业名 | 英文名为主。 |
| 定位 | 输出、坦克、治疗、召唤、支援、控制、探索等。 |
| Prime Perk | 主职业核心被动。 |
| Damage Perk | 输出向被动。 |
| Team Perk | 团队向被动。 |
| Utility Perk | 功能向被动。 |
| Relic Perk | 使用 Relic 后触发的被动。 |
| Skills | 主动技能列表。 |
| Trait | 职业特性。 |
| 起始装备 | 初始武器、防具、核心道具。 |
| 解锁方式 | 初始、商人、隐藏、DLC。 |
| 对本项目参考 | 可转译成角色机制、支援角色、战术模块等。 |

### 5.3 技能 / 模组字段

| 字段 | 说明 |
| --- | --- |
| 名称 | 技能或 Mod 名。 |
| 类型 | Archetype Skill / Weapon Mod。 |
| 资源机制 | 冷却、Mod Power 充能、Relic 触发等。 |
| 效果 | 伤害、控制、治疗、召唤、Buff、Debuff。 |
| 作用范围 | 单体、AOE、队伍、召唤物、区域。 |
| 可替换性 | 固定在职业上，还是可装在武器上。 |
| 构筑价值 | 是否能成为流派核心。 |
| 对本项目参考 | 可转译成角色技能、枪械插件、支援技、遗物效果。 |

## 7. 当前判断

后续如果继续深入，建议优先处理《遗迹2》的“职业与技能”和“装备与构筑”两条线，而不是先全量搬运所有装备。

原因：

- 本项目当前更需要系统设计参考，而不是数据库。
- 职业、技能、模组、戒指、项链最能体现“玩法如何被构筑改变”。
- 武器全量数据可以后置，先挑代表性样本做设计分析更有效。
