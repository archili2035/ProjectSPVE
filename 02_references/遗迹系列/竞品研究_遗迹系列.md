# 竞品研究：遗迹系列（Remnant）

资料采集日期：2026-06-23  
研究对象：`Remnant: From the Ashes`、`Remnant II` 及其 DLC / 长线更新 / 玩家反馈  
研究目的：为当前“角色驱动的 PVE 刷宝射击二游”方向提供玩法、内容结构、构筑系统、叙事呈现和长期运营参考。

---

## 1. 一句话判断

“遗迹系列”最值得参考的不是“第三人称射击 + 类魂”这个表层标签，而是它把以下几件事组合成了一个高复玩 PVE 框架：

> 程序化冒险结构 + 机制型 Boss + 横向构筑装备 + 隐藏收集 + 低门槛合作。

对本项目而言，它的价值在于证明：

- TPS / 肩射战斗可以和刷宝构筑结合。
- PVE 射击不必依赖开放世界，也可以通过“枢纽 + 世界石/副本入口 + 可重置冒险”建立长期循环。
- 随机化不只是房间拼接，也可以包括世界顺序、支线事件、Boss、NPC、奖励和解谜。
- 秘密、隐藏职业、隐藏装备可以强力驱动社区传播。

但它也暴露出明显风险：

- 程序化结构容易削弱主线情感和角色羁绊。
- 主角/角色存在感弱，玩家更记得世界、Boss 和装备，而不是角色。
- 隐藏内容过于晦涩时，会从“探索惊喜”变成“查攻略负担”。

---

## 2. 系列定位与核心循环

### 2.1 官方/商店定位

`Remnant II` 官方与 Steam 页面将其描述为：

- 《Remnant: From the Ashes》的续作。
- 第三人称动作 / 冒险 / RPG。
- 可单人，也可与最多两名好友合作。
- 玩家在多个恐怖、异质世界中对抗致命生物和神级 Boss。
- 通过装备、武器、物品、分支任务、制造和动态生成地下城获得重复游玩价值。

Steam 常见标签包括：

- Souls-like
- Co-op
- Action
- Third-Person Shooter
- RPG

### 2.2 可抽象出的核心循环

```text
Ward 13 枢纽
  ↓
世界石 / 关卡入口
  ↓
随机世界 / 随机副本 / 支线事件
  ↓
射击、近战、闪避、技能与资源管理
  ↓
精英怪 / 解谜 / 隐藏路线 / Boss
  ↓
材料、武器、模组、戒指、项链、特性、职业解锁
  ↓
构筑调整与强化
  ↓
重刷 Adventure / Campaign / Boss Rush / DLC 世界
```

这个循环对本项目很关键：它不是“开放世界探索”，而是“可重复进入、可变体组合、每次都有可能不同”的 PVE 冒险循环。

## 3. 战斗结构参考

### 3.1 基础战斗

遗迹系列的战斗由几层组成：

| 层级 | 作用 |
| --- | --- |
| 肩射 / 枪械 | 提供基础命中反馈、距离控制、弱点打击和火力节奏。 |
| 近战 | 提供补充输出、风险收益和部分流派玩法。 |
| 闪避 / 翻滚 | 提供类魂式生存节奏，要求观察敌人动作。 |
| 体力 / 弹药 / 治疗 | 限制连续行动，迫使玩家控制节奏。 |
| 武器模组 / 职业技能 | 提供主动爆发、控制、召唤、治疗、Buff 等构筑差异。 |
| Boss 机制 | 用空间、阶段、弹幕、召唤、弱点和特殊规则验证玩家操作与构筑。 |

它的战斗不是纯射击，也不是纯数值刷怪，而是把射击命中、翻滚无敌帧、技能冷却、资源控制和 Boss 机制叠在一起。

### 3.2 对本项目的参考意义

当前项目草案里提出“单主控角色 + 双支援角色”。遗迹系列可参考的是：

- 主控角色需要承担稳定的射击/闪避/走位体验。
- 枪械不能只是数值皮肤，要有节奏差异：精准步枪、霰弹、连射、充能、反弹、范围、弱点特化等。
- 技能和模组最好改变战斗方式，而不是单纯加伤。
- 支援角色可以学习遗迹中的职业技能定位：治疗、复活、召唤、控制、增伤、护盾、爆发。
- Boss 应同时验证“操作”和“构筑”，不能只做 DPS 木桩。

### 3.3 需要规避

- 不要让角色技能完全替代射击，否则会变成普通技能循环二游。
- 不要让射击只负责普攻填充，否则枪械价值不足。
- 不要把难度建立在不清晰的弹幕、镜头外攻击、怪物堆叠上。
- 合作模式要特别注意不同练度玩家组队时的缩放规则，遗迹系列曾被媒体指出组队缩放可能让低等级朋友加入后体验变差。

## 4. 程序化关卡与内容结构

### 4.1 遗迹系列的强项

遗迹系列的程序化不是单纯随机房间，而是更接近“冒险牌组”：

- 世界顺序可能不同。
- 同一世界中主线分支可能不同。
- 副本、事件、NPC、谜题、Boss、奖励可能不同。
- 有些支线/奖励在一次流程中根本不会出现。
- 玩家需要重刷或进入他人世界才能补齐内容。

PC Gamer 对 `Remnant II` 的一个重要观察是：游戏会随机化“不只是关卡布局，而是整个战役结构”，玩家一次流程只能看到整体内容的一部分。

### 4.2 对本项目的可用形态

可以转化为以下结构：

```text
基地 / 城市枢纽
  ↓
战区选择
  ↓
战区随机事件池
  ↓
主目标 + 支线事件 + 精英遭遇 + 异常点
  ↓
裂隙 / Boss / 特殊奖励房
  ↓
结算与返回基地
```

对“异常收容 / 都市怪谈 / 复古科技 / 移动据点”这类题材尤其合适：

- 异常区每次进入发生变化，有叙事合理性。
- 隐藏档案、异常实体、调查记录可以作为探索奖励。
- 程序化事件可以承载不同角色小剧情或阵营委托。
- Boss 可以作为“异常个体”或“污染核心”出现。

### 4.3 不应照搬的地方

遗迹系列的主线常被评价为“功能性强，但情感弱”。如果本项目是角色驱动二游，不能只做“酷世界 + 酷 Boss + 酷装备”。需要额外保证：

- 每个战区和副本要能反哺角色关系、阵营关系或角色个人线。
- 随机事件中应有角色语音、支援角色插话、档案补全和羁绊信息。
- 随机化不能破坏关键角色剧情的连续性。
- 核心剧情内容不要隐藏在极低概率或必须查攻略的路径里。

## 5. 构筑系统参考

### 5.1 遗迹系列的构筑层

`Remnant II` 的构筑大体由以下层级组成：

| 层级 | 功能 |
| --- | --- |
| Archetype / 职业 | 提供主动技能、被动、特性和战斗定位；后期可双职业组合。 |
| Long Gun / Handgun / Melee | 决定主要射击节奏、距离、伤害模式和手感。 |
| Weapon Mod | 装在武器上的主动能力，通常由战斗充能。 |
| Mutator | 武器被动改造，强化某类玩法。 |
| Relic | 治疗或关键生存/增益物品。 |
| Trait | 长期被动成长，多为数值向。 |
| Amulet / Rings | 重要构筑件；一个项链 + 多个戒指形成流派组合。 |
| Armor | 提供防御和负重，但在 `Remnant II` 中构筑存在感相对弱。 |

### 5.2 适合本项目吸收的原则

遗迹系列的装备价值更多是“横向变化”，而不是无限追求更高装等：

- 武器要有明显的使用体验差异。
- 模组/插件应改变输出方式或战术选择。
- 戒指/项链类小件可以承担 Build 拼图功能。
- Boss 材料可以转化为专属武器或模块，形成明确目标。
- 隐藏职业/隐藏装备可作为强社区传播点。

对应到当前项目，可考虑：

```text
角色：决定战斗机制、商业化入口、队伍定位。
枪械：决定射击手感、射程、节奏和基础输出结构。
战术模块 / 遗物：改变技能、射击、异常、召唤、护盾、换弹等流派。
词条 / 小件：提供刷宝追求和细节优化。
Boss 材料：提供目标明确的制造/解锁路径。
```

### 5.3 需要规避的系统问题

- 特性/被动如果都是 `+1%`、`+2%` 之类，玩家感知弱。
- 关键构筑件如果完全依赖低概率随机，会导致定向刷取焦虑。
- 隐藏职业/隐藏装备如果需要数据挖掘级解法，会让普通玩家挫败。
- 防具系统如果缺少改造和外观价值，会成为构筑短板。

## 6. Boss、秘密与社区传播

### 6.1 Boss 设计

媒体普遍认为 `Remnant II` 相比前作显著强化了 Boss：

- 更少依赖“Boss + 杂兵潮”的简单压迫。
- 更多使用独立机制、空间规则、阶段变化和视觉记忆点。
- 有些 Boss 接近关卡谜题，而不是单纯血条战斗。

对本项目来说，高难 Boss 可以承担：

- 验证构筑强度。
- 验证射击命中和走位。
- 产出专属材料、皮肤、称号、档案。
- 作为版本传播节点。

### 6.2 秘密内容

遗迹系列很擅长用隐藏内容制造社区讨论，例如隐藏职业、隐藏武器、复杂谜题、多结局任务。

可参考做法：

- 隐藏档案串联世界观。
- 隐藏 Boss 或异常实体作为探索奖励。
- 隐藏支援角色语音/小剧情增强角色感。
- 隐藏模块提供横向玩法，而不是绝对数值碾压。

需要控制：

- 核心成长不要过度依赖隐藏内容。
- 隐藏内容可以难找，但不要完全不可推理。
- 对二游用户，要避免“错过焦虑”过强。

## 7. 叙事与世界观呈现

### 7.1 遗迹系列的叙事结构

遗迹系列主线通常比较功能性：

- 人类幸存者。
- 世界石 / 多世界穿梭。
- Root 威胁现实。
- 玩家通过不同世界寻找线索和关键物。

真正有记忆点的是各个世界内部的小叙事：

- Losomn：哥特、低幻想、宫廷、城市、梦魇感。
- N'Erud：宇宙科幻、机械星球、灭亡文明。
- Yaesha：腐化自然、异族文明、生态灾变。
- 支线、书籍、物品描述、NPC 事件提供局部故事。

### 7.2 对本项目的启发

如果项目走“异常都市 / 复古科技 / 移动据点”，可以借鉴“世界内局部故事强于宏大主线”的方式，但必须补足角色驱动：

- 每个异常战区对应一组角色立场、历史或创伤。
- 档案系统不只是文本收藏，而是角色关系、怪物生态和阵营秘密的共同索引。
- 重刷副本时可以通过不同角色支援组合触发不同旁白/调查口径。
- 装备和遗物可以带叙事标签：来源、异常等级、事故记录、角色评价。

## 8. 长期更新与模式参考

### 8.1 DLC / 更新结构

遗迹系列的更新包括：

- 新世界区域。
- 新职业 / Archetype。
- 新 Boss。
- 新武器、模组、戒指、项链。
- 新剧情线。
- Boss Rush。
- Prism / 碎片系统等长期构筑强化。

其中 `Boss Rush` 很值得关注：它把原本分散在流程中的 Boss 变成高密度挑战容器，适合后期玩家验证构筑。

### 8.2 对本项目的版本思路

可以转化为：

- 每个大版本推出一个战区或异常主题。
- 搭配 1-2 名核心角色、若干支援角色剧情、Boss、专属模块和遗物。
- 常驻玩法用“战区 / 裂隙 / Boss Rush / 调查档案”承接。
- 活动玩法可以是某个异常规则的临时变体。
- 高难模式不只提升数值，也改变 Boss 机制和环境规则。

## 9. 对本项目的可借鉴点

### 9.1 最值得借鉴

1. **枢纽 + 可重置 PVE 世界**  
   不必做完整开放世界，也可以建立长期探索和刷宝。

2. **程序化冒险牌组**  
   随机的不只是房间，而是事件、NPC、Boss、奖励、谜题和局部故事。

3. **构筑件横向差异**  
   枪械、模组、遗物、小件装备要改变打法，而不是只堆数值。

4. **Boss 作为构筑验证器**  
   Boss 既要考操作，也要考 Build，不应只是血量墙。

5. **隐藏内容驱动社区传播**  
   隐藏职业、隐藏武器、隐藏档案、隐藏 Boss 都适合形成讨论。

6. **合作是加分项，不一定是唯一核心**  
   单人体验要成立，合作体验增强战术和社交。

### 9.2 本项目必须另做的部分

1. **角色情感连接**  
   遗迹系列不是角色驱动，不能照搬其弱主角/弱羁绊结构。

2. **二游商业化边界**  
   角色抽取、装备刷取、武器获取之间要避免互相削弱。

3. **低门槛引导**  
   遗迹玩家可以接受较高试错成本，二游用户未必能接受。

4. **移动端/多平台适配**  
   翻滚、瞄准、弱点、Boss 机制需要根据平台输入重新验证。

## 10. 后续值得专门拆解的问题

1. 遗迹的“世界石”结构是否可以转译为本项目的“异常入口 / 战区门 / 远征路线”？
2. 本项目的随机化应该发生在哪些层：房间、事件、Boss、掉落、角色语音、档案？
3. 隐藏内容应该奖励战力、横向玩法、外观，还是世界观资料？
4. 是否需要类似 Boss Rush 的高密度构筑验证模式？
5. 枪械模组是否可以成为“支援角色技能”的外部化载体？
6. 如何避免“程序化副本”冲淡角色主线？
